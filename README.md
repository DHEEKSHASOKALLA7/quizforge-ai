# QuizForge AI — Real-Time AI Quiz & Learning Analytics Platform

QuizForge AI is a full-stack AI-powered assessment platform for teachers and students.

It combines AI-generated quiz creation, source-grounded question generation from uploaded learning material, real-time multiplayer assessments, server-authoritative scoring, live leaderboards, persistent results, and AI-powered learning insights.

Teachers can create quizzes from technical or academic topics or upload course material such as PDFs and documents. Students join live quizzes using a room code or shareable link and participate in real time.

---

## ✨ Features

### 👩‍🏫 Teacher Features

- Teacher and student role-based accounts
- AI-powered quiz generation from topics
- Source-grounded quiz generation from uploaded learning material
- Support for PDF, DOCX, PPTX, TXT, Markdown, CSV, JSON, HTML and source-code files
- Configurable number of questions
- Configurable difficulty
- Live quiz hosting
- Shareable quiz links
- Room codes
- QR-code based joining
- Real-time response monitoring
- Teacher-only answer reveal
- Response distribution
- Class performance analytics
- Weak-concept identification
- Common wrong-answer analysis
- AI-powered re-teaching recommendations
- One-click remedial quiz generation
- Student performance history

### 👨‍🎓 Student Features

- Student-only quiz participation
- Join quizzes using room codes or shareable links
- Real-time timed questions
- Server-authoritative scoring
- Speed-aware scoring
- Live leaderboard
- Reconnect/resume support
- Late joining of active quizzes
- Synchronized remaining question timer
- Personal performance history
- Final score and rank after quiz completion

Students cannot create quizzes, generate AI quizzes, upload learning material, host quizzes, or access teacher analytics.
